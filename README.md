That allows you to read/write project, patterns and instrument data. Alongside a [Instrument Editor](https://github.com/sandroidmusic/tracker-mtp-editor) and a [Pattern Editor](https://github.com/sandroidmusic/tracker-mtp-editor) example.
* I've helped writing the firmware and software for the awesome [KB1 Mini Keyboard Project](https://github.com/PocketMidi/KB1) for the [Polyend Tracker Mini](https://polyend.com/tracker-mini/).
* How about a [web based second screen solution](https://github.com/sandroidmusic/obs-2nd-Screen) for [OBS](https://obsproject.com/) that is entirely free.
* Interested in a a [web based projection mapping framework](https://github.com/sandroidmusic/projector), that can react to [live music and to MIDI events](https://www.youtube.com/watch?v=J2pfZ2ajXEs).
